# Supabase Free สำหรับเว็บผลงาน

โปรเจกต์ Free ของพอร์ตโฟลิโอถูกสร้างแล้ว ตั้งค่า Project URL, publishable key และ RLS ใน `supabase-config.js` กับ `supabase-setup.sql` แล้ว ฐานข้อมูลมีตารางผลงาน/ไฟล์ และ bucket `portfolio-files` แบบ public-read, admin-write

Supabase Free มี Storage 1 GB และจำกัดขนาดไฟล์ 50 MB ต่อไฟล์ตามแผนปัจจุบัน โปรเจกต์ฟรีอาจ pause หลังไม่มีการใช้งานหนึ่งสัปดาห์ และมีโควตาฐานข้อมูล/ทราฟฟิกตามหน้า pricing

## สิ่งที่เหลือ

1. เปิดอีเมลเชิญ Supabase แล้วทำขั้นตอนยืนยัน/ตั้งรหัสผ่านบัญชีผู้ดูแลให้เสร็จ
2. เปิดพรีวิวเว็บ ล็อกอินด้วยอีเมลผู้ดูแล แล้วเพิ่มผลงานใหม่ งานที่เพิ่มหลังล็อกอินจะบันทึกออนไลน์
3. งานที่เคยบันทึกไว้ใน IndexedDB ของพรีวิวไม่ได้ย้ายขึ้น Supabase อัตโนมัติ ต้องเพิ่มใหม่หรือทำขั้นตอนนำเข้าแยก
4. เว็บยังต้อง deploy บน static hosting ด้วย HTTPS ก่อนที่ผู้เข้าชมคนอื่นจะเปิดผ่าน URL สาธารณะได้

ผู้เข้าชมอ่านผลงานและไฟล์ได้ แต่การเพิ่ม/แก้ไข/ลบจำกัดเฉพาะอีเมลผู้ดูแล ห้ามนำ `service_role` key มาใส่ในเว็บไซต์หรือส่งในแชต
